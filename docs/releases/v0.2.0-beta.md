# v0.2.0 Beta

First public beta of the independent Windows launcher. NEURAL OVERDRIVE plays a five- or nine-second sequence with simulated telemetry. A direct mode uses the Windows app entry without animation. Launcher Settings offers English and Simplified Chinese, animation-only preview, local preferences and desktop shortcuts.

## Download and run

- `CodexBootAnimation-0.2.0-beta-win-x64.zip` includes the .NET Windows runtime. The `.sha256` sidecar lets you verify the download.
- Extract to a writable folder, then double-click `CodexBootAnimation.exe`. Run `CodexBootAnimation.exe --settings` to save preferences and set up the daily launch shortcut.
- Animation uses Microsoft's Evergreen WebView2 Runtime. Launching the client uses the registered ChatGPT desktop app. The launcher is unofficial and unaffiliated with OpenAI.

## Compatibility and validation

- The beta executable is unsigned. Windows may display a publisher or SmartScreen warning. Behavior under other Windows security policies remains unverified.
- Local Windows 11 x64 testing covered settings at 150% scaling, portable relocation, independent preview, an already-running client and injected theme and WebView2 failures.
- Clean Windows installations, other architectures or Windows versions, cold ChatGPT activation and its resulting destination, actual missing Evergreen, mixed-DPI displays, minimized-window restoration and interactive focus changes remain unverified. The actual Windows client chooses which screen opens.
- All 22 automated tests passed. A fresh NuGet.org audit of direct and transitive application packages reported no known package advisories for the resolved versions.
